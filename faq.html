Frequently asked questions

How do I change the look without changing presets?

Theme settings › Colors and Typography set colors and fonts, and Header › Style and Footer › Style each offer ten styles. Between them you can match any preset.

How do I make a mega menu?

Set Header › Menu type to "Mega menu" and give a top-level menu link child links (and grandchild links for columns). To add promo images, add a "Mega menu promo" block and type the link's title in "Menu item". See Mega menus and promos.

Can a mega menu show more than two promos?

Yes: add another Mega menu promo block with the same menu item. Promos from every matching block show in a row.

Why don't animations play right when the page opens?

To keep pages fast, the animation scripts load on the visitor's first scroll, tap or mouse movement. Whatever is on screen at that point stays as it is, and everything below animates in as they scroll. If nothing animates at all, check Theme settings › Animations and whether your device has "reduce motion" turned on.

How do I add a size chart or care instructions?

Write the content as a page in Shopify admin › Online Store › Pages, then add a "Collapsible tab" or "Tabs" block to the product page and choose that page.

How do I show a countdown for a sale?

Add a "Countdown timer" block to the product page, or a countdown to an Announcement block in the header, and set the end date and time.

Where do filters come from?

From Shopify's free Search & Discovery app. Install it, choose your filters there, then turn on "Enable filtering" in the collection and search sections.

How do I offer gift wrapping?

Create a gift wrap product and choose it in Theme settings › Cart › Gift wrap product. See Gift wrap.

My banner image is cropped badly on phones. What can I do?

Set a focal point on the image (image picker › Edit), or add a separate mobile image where the section offers one.

How do I use Zoom reveal and Runway?

Add them from Add section on the home page. Zoom reveal cuts a word out of the section's color to show your image through its letters; Runway pairs model images with products. Both need animations on. See Zoom reveal and Runway.

Can I edit the theme's code?

Yes, but duplicate the theme first and edit the copy. Edited code can't receive theme updates automatically, and support doesn't cover changes to the code.

How do I update MOHINI?

When an update is out, Shopify shows it in Online Store › Themes. Adding the update creates a new copy with your settings and content carried over; review it and publish it. Changes you made to the code aren't carried over.

Does MOHINI work with apps?

Yes. Sections and the product page accept app blocks, and apps that add their own sections or embeds work as usual. We can't support the apps themselves; contact the app's developer for help with an app.
