Header and footer

The header and footer appear on every page. Each has ten styles, and each style has its own layout, type and decoration.

Header styles

Header › Style sets the layout: Beauty and Jewelry center the logo with search on the left; Clothing centers it with the menu on the left; Electronics, Food and drink, Pets and Toys put a wide search beside the logo; Kids, Services and Sports put the menu beside the logo.

Other header settings: logo and mobile logo, colors (by color scheme or your own), menu type (dropdown or mega menu), search style, which icons and labels show, announcement bar, top bar, country and language pickers, category shortcuts, sticky header (always, on scroll up, or off) and a transparent header over the first section of the home page.

Menus

Build menus in Online Store › Navigation. A top-level link with child links opens a dropdown; with Menu type: Mega menu, it opens a full-width panel instead. Child links with their own children become columns with headings.

Mega menus and promos

Add a Mega menu promo block to the header and type the menu link's title in Menu item (for example Catalog). That link then opens a mega menu with promo cards beside its columns.

  • Each block has two promos (image, heading, text, link) and a button label. Leave promo 2's image and heading empty to show one promo.
  • More than two promos: add another Mega menu promo block with the same menu item. Promos from every matching block show in a row, in block order.
  • Text position: below the image, or on the image over a dark overlay (good for offers like "50% off"). Set the overlay strength with Image overlay opacity.
  • Image ratio: the header style's default, portrait, square, landscape or wide. Landscape and wide promos are also wider.
  • Without an image, a promo shows a tinted frame (the placeholder art only shows in the theme editor).

Example: four link columns and one wide offer image. Give the menu link four child links, each with its own links. Add a Mega menu promo block for that link with promo 1 only, Text position "On the image", Image ratio "Wide" and the heading "50% OFF".

Menu labels

A Menu label block adds a small badge (like "Hot" or "New") next to a menu link. Type the link's title in Menu item and choose the badge text and colors.

Announcement bar

Add Announcement blocks for messages that rotate above the header. Each can have an icon, a link and a countdown to a date and time.

Footer

Footer › Style sets the colors, type, decoration and where the newsletter signup sits. Add blocks for menus, text, contact details, a promo image and store promises (like free shipping). Other settings: brand logo and text, newsletter signup, a very large store name across the bottom and the bottom bar (payment icons, policies, country and language pickers, copyright).
